## 图表功能

- 营地同款橙色折线，按天分段，一眼看清每天的走势
- 鼠标悬停（手机点按）任意数据点，显示当局详情：日期时间、英雄、胜负、KDA、MVP / 牌子、本局分差、赛后积分

- 英雄、KDA、时间、胜负、MVP / 牌子：王者营地战绩实测

## 更新方式

每打完一场向 Muse 汇报结果（胜负 + 分差，或直接发战绩截图），Muse 更新 `index.html` 的数据并提交到本仓库，GitHub Pages 自动重新发布，刷新 [peak.oobear.top](https://peak.oobear.top) 即可看到最新曲线。

## 纪律（冲分规则）

- 只在 19:00 后打，开打前先报当前分数，单日最多 4 把
- 中路单日最多 2 把（守巅峰全能分路标），孙权单日最多 1 把
- 净赚 +15~20 收手；净 -30 或 2 连败立刻停；0 点后不打
